# Атлас людини

Інтерактивний 3D-атлас анатомії людини українською мовою. Побудований на React, Three.js і shadcn/ui. Модель дорослого чоловіка з бази BodyParts3D розбита на **2 234 окремі елементи**, які можна вибирати. Атлас охоплює **15 анатомічних систем** і **3 432 названі поняття**.

**[Відкрити атлас](https://maks21787-jpg.github.io/Anatomy-Atlas-Ukraine-/)**

Проєкт є українською адаптацією [ashemag/human-atlas](https://github.com/ashemag/human-atlas).

## Моделі

- **Чоловік · тіло** — BodyParts3D 4.0 (DBCLS, CC BY 4.0): 2 234 елементи, 3 432 названі поняття, повне тіло.
- **Жінка · тулуб** — Human Reference Atlas 3D Reference Organ Library (HuBMAP / NIH, CC BY 4.0), реконструйована за Visible Human Female: 264 структури хребта, таза, органів черевної порожнини й малого таза, судин і молочних залоз. Вибірку структур і латинські назви за Terminologia Anatomica 2 взято з відкритих даних проєкту [Anatria3D](https://github.com/Nurkan1/Anatria-3D) (файли `*_female.glb`, `manifest_female.json`, CC BY 4.0). Модель перетворено скриптом `scripts/convert-female-hra.mjs`, джерела й зміни описано в `public/models/female/NOTICE.md`.

Моделі зберігаються в окремих теках (`public/models/` і `public/models/female/`) і перемикаються в бічній панелі.

## Можливості

- **Пошук** українською, латиною та англійською: слова в будь-якому порядку й відмінку («нирки ліва», «arteria renalis»), підсвічування збігів, навігація стрілками.
- **Каталог за системами**: фільтр показує всі структури системи за абеткою.
- **Режими показу систем**: показати або сховати, «Рентген» (напівпрозора система), «Соло» (лише ця система), а також «Скляне тіло», де напівпрозорим стає все, крім вибраного.
- **Підписи вибраного** на полях із лініями-виносками, українською або латиною, як в атласі-альбомі.
- **Зрізи** в поперечній, фронтальній і сагітальній площинах з повзунком положення.
- **Сканер**: площина світла проходить тілом, підсвічує кожну структуру, яку перетинає, і називає найбільші з них. Рівень можна зафіксувати.
- **Робота з вибором**: підказка з назвою при наведенні, вибір кількох структур (Ctrl + клік), ізоляція, приховування, «Судини поруч» (додає артерії й вени, що проходять біля вибраної структури).
- **Картка структури** з латинською назвою, описом, переходами до складових частин і до більшої структури та кнопкою «Назад».
- **Навчання**: нотатки до структур, історія переглядів і карта вивченого, яка підсвічує на тілі те, що ви вже опрацювали. Дані зберігаються лише в браузері.
- **Камера**: вписати в екран, види спереду, ззаду, зліва, справа й згори, масштаб, плавне наближення до вибраного, автообертання.
- **Збереження вигляду** як зображення PNG разом із підписами.
- Темна й світла теми, клавіатурні скорочення (натисніть «?» у застосунку), адаптивний інтерфейс для телефона.

## Що перекладено

- Увесь інтерфейс: панелі, кнопки, підказки, повідомлення про помилки, розділ «Джерела й авторство».
- Назви й описи систем, пояснення для ключових органів.
- Латинські назви для всіх структур у `public/models/names-la.json` (за Міжнародною анатомічною термінологією; для службових понять FMA — описові латинські відповідники).
- Усі 3 432 назви анатомічних понять і 2 234 назви елементів. Словник лежить у `public/models/names-uk.json`: ключ — англійська назва BodyParts3D у нижньому регістрі, значення — український відповідник.

Назви перекладено за українською анатомічною термінологією (Міжнародна анатомічна номенклатура). Вихідний файл `public/models/atlas.json` не змінено: переклад застосовується під час завантаження (`localizeAtlas` у `app/anatomy.ts`). Англійська назва зберігається в полі `nameEn`, показується в картці структури й бере участь у пошуку.

Службові поняття онтології FMA (наприклад, «anatomical entity», «organ component») перекладено дослівно, бо вони відображають ієрархію джерела, а не конкретні органи.

## Локальний запуск

Потрібен Node.js 22.13 або новіший. API-ключі й облікові записи не потрібні.

```sh
npm ci
npm run dev
```

Відкрийте http://localhost:3016. Статичну збірку створює `npm run build`, результат з'являється в теці `dist/`.

## Перевірка

```sh
npm run check
node scripts/validate-atlas.mjs
node scripts/validate-interactions.mjs
npm run build
```

Перевірки охоплюють буфери геометрії, назви та належність до понять, розкладку розібраної моделі без накладань для десктопних і мобільних пропорцій, контракти пошуку й інспектування, а також розрізнення дотику й перетягування.

## Анатомічні дані

Атлас використовує **BodyParts3D 4.0** — референсну анатомію дорослого чоловіка за ліцензією **CC BY 4.0**. Модель не охоплює всіх структур тіла людини та їхніх варіантів. Окремі вихідні моделі відрізняються від названих понять: одне поняття може об'єднувати кілька елементів.

Геометрію спрощено для роботи в браузері, при цьому збережено кожну вихідну модель. Пакет містить 2 288 268 трикутників, обсяг стиснутої геометрії для завантаження становить близько 33 МБ. Повні дані про авторство, посилання на джерела й опис змін наведено в [ATTRIBUTION.md](public/ATTRIBUTION.md).

Атлас призначений для навчання і не є інструментом діагностики чи планування операцій.

## Як це працює

Геометрія об'єднана в пакети. Текстури на GPU для кожної структури керують зсувом, видимістю та виділенням, а окрема геометрія компонентів забезпечує точний вибір курсором. Розкладка розібраної моделі враховує лише видимі елементи. Сцена перемальовується тільки після змін, тому обертання залишається плавним без тисяч окремих викликів малювання.

Необов'язкові інструменти WebMCP дають змогу сумісним браузерам шукати й відкривати анатомічні структури. Видимий інтерфейс працює і без них.

## Перебудова геометрії

Репозиторій уже містить готову для браузера геометрію. Щоб перебудувати її, завантажте офіційний архів OBJ BodyParts3D і англійські таблиці метаданих, підготуйте об'єднані поняття та відповідність системам, запустіть `scripts/convert-anatomy.py`, потім `node scripts/optimize-anatomy.mjs` і `node scripts/compress-models.mjs`. Спрощення використовує межу відносної похибки 0,2 % для кожної структури. Після перебудови перевірте, чи всі нові назви є в `public/models/names-uk.json`: назви без перекладу показуються англійською.

## Розгортання

Опублікована версія розміщена на GitHub Pages і роздається з гілки `gh-pages`, яка містить вміст теки `dist/`. Сайт оновлюється автоматично: після кожного пушу в гілку за замовчуванням або `main` workflow `.github/workflows/deploy.yml` перевіряє типи, запускає тести взаємодії, збирає проєкт і публікує `dist/` у гілку `gh-pages`. Його також можна запустити вручну на вкладці Actions (Run workflow).

Імпортуйте репозиторій у Vercel як проєкт Vite. Файл `vercel.json` налаштовує `npm ci`, `npm run build` і вихідну теку `dist`. Сайт також можна розмістити на будь-якому статичному хостингу.
